## 🚀 Featured Projects

**🗂️ Afridata — Dataset Discovery Platform**
Metadata inferencing service and hybrid recommendation engine for a dataset discovery platform deployed across 15 African countries. Built and later led development of this during my Backend Engineering internship at Jhub Africa.
`Django` `PostgreSQL` `Redis` `Celery` `scikit-learn`

**🗺️ Locus — B2B GIS Geocoding Platform**
Solo-founded platform that translates GPS coordinates into structured Kenyan administrative addresses (Ward, Constituency, County) via spatial joins.
`FastAPI` `PostGIS` `Python`

**⚙️ [State-Space](https://github.com/state-space-cluster) — Distributed Computing Engine**
A GitHub organization of repos powering a distributed algorithmic engine — an async DRF backend for matrix multiplication jobs and NFA/DFA automata construction, paired with a React + TypeScript frontend for interactive visualization.
- [state-space-backend](https://github.com/state-space-cluster/state-space-backend)
- [state-space-frontend](https://github.com/state-space-cluster/state-space-frontend)
